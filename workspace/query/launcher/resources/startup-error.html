启动失败

程序没能完成启动自检。下面是具体缺什么、在哪，以及可以照做的步骤。

具体问题

（此处由程序填入：缺哪个文件、在哪个路径、期望的结构是什么）

可以照做的步骤

  1. 确认解压是**完整**的：bin/、data/、environment/ 三个目录必须同在，缺一不可。
  2. 确认程序目录**没有被单独移动**过（例如只把 bin/ 拷走）。
  3. 确认杀毒软件没有隔离 environment/ 下的 llama-server.exe 或模型文件。
  4. 仍然不行：把本页「具体问题」里的路径连同 data/runtime/logs/app.log 一起反馈。
